Cara Menghubungkan ke Google Sheets

  1. Buka Google Cloud Console, buat project baru, lalu aktifkan Google Sheets API di menu Library.
  2. Di menu OAuth consent screen, pilih External, isi nama aplikasi, dan masukkan email kamu di bagian Test users.
  3. Di menu Credentials, buat OAuth client ID bertipe Web application.
  4. Pada bagian Authorized JavaScript origins, masukkan URL GitHub Pages kamu (contoh: https://username.github.io).
  5. Salin Client ID yang dibuat, lalu tempelkan bersama URL Google Spreadsheet kamu di panel Koneksi aplikasi ini.
  6. Pastikan baris pertama (baris 1) di Google Spreadsheet kamu berisi judul kolom (misal: Nama, Status, Catatan).
